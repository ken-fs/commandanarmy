Gems matter more in Command An Army than free currency in most Roblox games: summons cost a lot, class swaps eat the same currency, and a thin Gem stack leaves you fielding starter troops while the enemy line is already full of Spartans. Codes are the fastest way to skip that grind.

## How do I redeem Command An Army codes?

The codes box is easy to miss because it is **locked until you finish the tutorial**. Once you are through it:

1. Open Command An Army on Roblox and spawn into the lobby.
2. Find the **Codes button on the right side of the screen**.
3. Tap the box and **paste** one code from the list above — copy-paste, don't type; codes are case-sensitive and a missing letter reads as "invalid".
4. Hit **Claim** and check that the Gems land in your balance.
5. Repeat for every code in the active list — it takes about a minute for all seven.

**Redeem troubleshooting** — if an active code is rejected:

- **"Invalid code"**: it most likely expired since our last check — codes rotate with every update. Leave a comment and we will re-test within the day.
- **"Already redeemed"**: each code works once per account. This includes milestone codes like 10KGoal.
- **Nothing happens when you tap Claim**: rejoin the server and try again — the codes box occasionally needs a fresh session, a known quirk after patches.

## Why do codes stop working?

Command An Army codes are milestone and update codes: the developer attaches them to like-count goals, patches, and balance changes. When the next update ships, the previous batch retires — that is why BUGFIX, LEBALANCE, and CONQUEST all moved to the expired list within weeks of release.

**BUGFIX** and **LEBALANCE** used to be contested, but not anymore. GameRant listed them as expired on September 16, and Pocket Tactics now lists both as expired too. Don't waste time on them.
